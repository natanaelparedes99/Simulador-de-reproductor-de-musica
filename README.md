# Gestor de Listas de Reproducción (TAD Lista Doble Circular)

Implementación de una lista doblemente enlazada circular para la gestión y reproducción simulada de canciones, cumpliendo con operaciones en tiempo constante $O(1)$ y lineal $O(n)$ según la estructura de datos.
